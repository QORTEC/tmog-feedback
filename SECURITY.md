# Security policy

Please do not disclose suspected security vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** button on this repository's Security
page. That creates a private report visible only to the reporter and the TMOG
maintainers.

Include the affected TMOG version and build, macOS or Windows version,
reproduction steps, impact, and any proposed mitigation. Remove unrelated
personal or system information before attaching logs or screenshots.
