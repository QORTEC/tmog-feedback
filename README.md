# TMOG Feedback

This public repository is the issue tracker for
[Task Manager TMOG](https://www.tmog.org/). The application source code is
maintained separately in a private repository.

Use the issue forms to:

- [Report a bug](https://github.com/davepl/tmog-feedback/issues/new?template=bug-report.yml)
- [Request a feature](https://github.com/davepl/tmog-feedback/issues/new?template=feature-request.yml)

Before posting, remove usernames, addresses, process arguments, file paths,
network identifiers, and any other private information from screenshots or
diagnostic text.

Security vulnerabilities should not be filed as public issues. Follow the
instructions in [SECURITY.md](SECURITY.md) instead.

TMOG beta downloads and product information are available at
[tmog.org](https://www.tmog.org/).
